Update the title screen to feature the animated swirling whitehole sprite and custom bold pixel typography for the "High: <score>" and "Press A" texts, matching the style of the "SuperMassive WhiteHole" title art.

## User Review Required

> [!IMPORTANT]
> - **Whitehole Position**: The static whitehole in `title_screen.png` is located at `(x=92, y=30)`, which exactly matches frame 3 of `whitehole_32.png`. > - **Font Styling**: A custom 7-pixel bold font is introduced matching the 2-pixel stroke and rounded styling of "SuperMassive WhiteHole". It supports letters (A-Z, a-z), digits (0-9), and punctuation (`:`, ` `, `-`, `!`) with zero dynamic RAM usage (stored in `PROGMEM`, ~619 bytes total Flash).
> - **Text Layout**:
>   - High score: `High: <score>` at `x=6, y=38` using standard 5×7 font (smaller, secondary text)
>   - Action prompt: `Press A` at `x=6, y=50` using custom bold title font (primary call-to-action)
